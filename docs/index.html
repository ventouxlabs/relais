RELAIS

Your own relay station for AI

Relais turns an Android phone into a headless, always-on LLM node. It runs a language model directly on the phone's GPU and neural silicon, and serves it over your LAN as a standard OpenAI-compatible API. Point any OpenAI client at the phone and it answers.

Install it on a spare phone, plug it in, put it on a shelf. There is no chat UI to babysit — it auto-starts, survives Doze, recovers from crashes and OOM kills, and draws a few watts. It is inference infrastructure you leave running.

Talk to it

$ curl -k https://192.168.1.42:8443/v1/chat/completions \
    -H "Authorization: Bearer $RELAIS_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"gemma-4-E4B-it",
         "messages":[{"role":"user","content":"ping"}]}'

The LAN surface is HTTPS on :8443, with a TLS certificate generated on the device — hence -k, or pin the cert. Plain HTTP on :8080 is bound to loopback only and is not reachable from the network. The bearer key is generated on-device and stored encrypted; the node is found automatically over mDNS.

What it is not

Relais will not outrun a desktop GPU on raw tokens per second, and does not pretend to. Its value is different: always-on, low-power, private, zero-marginal-cost inference. Use it for small-model workloads, agents, automation, and home-lab pipelines that need a local endpoint that is simply always there.

Sovereignty

  • Inference happens on the device. Prompts and completions never leave your network, and once a model is downloaded Relais runs fully offline.
  • No cloud calls, no per-token bill, no third party in the loop. No analytics, no telemetry, no account system.
  • The API is served only on your local network, behind an access key you control. You start and stop it.
  • You operate this infrastructure; you do not rent it.
